# Five-wave self-rated memory item review

Date: 2026-10-25. This review compares the official questionnaire wording and Codebook categories for the self-rated current-memory item in 2011, 2013, 2015, 2018 and 2020. It does not use respondent records or Codebook frequency counts.

The questionnaires ask one subjective question about current memory in all five waves. Wave 1–4 use `dc004`; Wave 5 uses `dc006`. Each Codebook lists ordered responses from 1=Excellent to 5=Poor. The 2020 Chinese questionnaire and Codebook additionally list `997=Don't Know`. The Wave 4 questionnaire's Chinese prompt explicitly matches the Chinese Wave 5 item despite the English extraction around Wave 4 containing a conflicting neighboring month label; the Codebook's `dc004` field label is Self-Rated Memory.

This supports a shared broad candidate concept (`cog_subjective_memory`) while preserving original wave codes, module labels and item records. The field is a subjective rating, not an objective memory-test score or diagnosis. Categories appear directionally aligned, but that alone does not establish equal administration, identical eligible samples, absence of unlisted special missing values, or a valid pooled estimand. Keep analyses wave-specific until release-level eligibility and special-code QA are complete; do not derive a pooled score or describe the mapping as analysis-ready.
