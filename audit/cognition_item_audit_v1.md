# CHARLS 认知任务逐波编码映射审计 v1

更新：2026-10-16

## 结果与范围

新增可复现脚本 `scripts/build_cognition_item_crosswalk.py`，以公开变量元数据的实际字段为边界，并结合五波 CHARLS 官方问卷中的题目说明，生成 `cognition_item_variable_mapping_v1.csv` 和网站 JSON。当前含341条“概念—波次—源字段”候选映射，覆盖17个概念，未读取个体数据、未派生量表/认知总分。字段级映射数量包括多选题拆分字段、多个答案槽位和重复回忆词项；不等于独立测量指标数。

概念目录覆盖自评记忆、时间/地点定向、连续减7、五边形临摹、多词即时/延迟回忆、2018动物命名流畅性和CSI-D单题、词回忆施测情况、2018三物品学习/延迟回忆，以及命名、句子重复、阅读/执行指令、书写任务等。原宽规则曾把2018动物命名、CSI-D和施测条件错误归入“词语再认”，本轮已拆分为相应任务并移除空气质量满意度字段。不同波次任务形态不同，不能将2020十词测试与2018三物品记忆测试合并为同一原始指标。

## 核对到的设计差异

- **时间定向：**2011–2015使用年/月/日、星期、季节等多个拆分字段；2018和2020题号、覆盖项目不同。2018另含地点及地址/个人信息定向字段，属于扩展任务。
- **即时词语记忆：**2011/2015以 `dc006s*` 字段记录；2013为 `dc006_1` 至 `dc006_3` 多轮字段；2020问卷呈现 `dc012`、`dc013`、`dc014` 三组回忆字段。题表答案槽不能直接当作总分；要按词表版本及有效答案派生。
- **延迟记忆：**2011–2015 `dc027s*`、2018 `dc047_w4_s*`、2020 `dc028_s*` 分别是词语延迟回忆字段；2018另有三物品延迟回忆 `dc015_w4`。2020 `dc029` 是访员观察，不能凭题号误作延迟回忆。
- **空间临摹：**各波有相交五边形临摹候选字段（2011–2015 `dc025`，2018 `dc024_w4`，2020 `dc009`）。须核验评分规则、未评估码和图像/纸面记录后才可合并。
- **2018扩展模块：**官方问卷标示Cognition模块及多项扩展任务，受访者年龄/筛选与路由依问卷执行；项目记录显示60岁及以上完成全部测试，60岁以下只完成指定子集。不能假定所有波次所有人都有这些字段，也不能以空值作答错误或零分。

## 字段到题目的审计限制

本地 `raw_variable_catalog_v1.csv` 是模块字段清单，认知字段的 `variable_label` 多数为空。构建脚本现从2011/2013/2015/2018/2020官方代码本提取源字段标签。所有字段的概念映射仍由问卷正文语义确定，每条明确标注“候选映射”，没有把合成说明冒充官方标签。仍需逐字段补充精确问卷页码、题干、特殊缺失码、跳转路径和代理回答限制。

2018认知模块含限时动物命名流畅性及CSI-D部分单题。当前编码映射用于搜索定位，不表示已构成有效认知量表。计算时需预先指定每个任务的评分算法和样本资格，并在汇总网站展示算法版本、可用波次和 N。

## 值标签进展（2026-10-16）

本轮已为255/341字段补入官方类别标签或连续语义。新增跨波词语即时/延迟回忆标签，并按波次区分：2011–2015词表位置码、2018词项专属码、2020二元复选框；未选择值未被代码本证实时不猜为0。2020不知道/拒答、未评估码分开保留，2018三物品任务97未评估码不当作错误。认知概念也已纠正为即时回忆、延迟回忆、施测情况、动物命名流畅性和CSI-D条目等。详细字段标签与来源见`audit/cognition_value_label_review_v1.md`；运行`python scripts/build_cognition_item_crosswalk.py`再运行`python scripts/enrich_cognition_value_labels.py`重建。其余认知任务仍需值标签及路由审计。

## 可借鉴 NHANES PE Atlas 的展示思路

保留独立的编码检索页：可按概念/源字段/波次筛选；每条源字段展示模块、题目定义、适用波次、映射状态和注意事项。CHARLS 的编码按“波次 + 模块 + 变量名”唯一识别，不能只用如 `dc018` 的变量名跨波匹配。页面应分开展示原始字段目录、经审核概念目录与可分析结果，不能把拆分字段数量写成指标总数。


### 2018词语辨识任务增补（2026-10-16）

新增`cog_word_recognition`候选概念及20条2018词卡字段（`dc048_w4`–`dc067_w4`），依据官方WRE词语辨识部分题干与代码本。每项保留1=Yes、5=No、8=Don’t Know；是否形成正确/虚报分数需结合目标词/干扰词表和预先定义算法，本目录不合成分数。WRE仅限2018且有单独进入/拒答跳转。

### 2018 CHARLS-HCAP官方偏倚与跨波比较提醒（2026-10-22）

补读官方2023 Data Alert和2024 CHARLS-HCAP User Guidance，并按官方发布页核验版本。部分MMSE题可能受识字/视力影响，普通话改写的词表和短语任务可能不利于非普通话使用者，仙人掌命名和CERAD十词也可能受文化/教育背景影响。指南还要求区分无法回答、不知道、拒答、未施测等非数值回答，并提醒按识字/语言/感官条件做敏感性分析时要先定义目标人群，不能自动剔除。Wave 4十词记忆测试词表和施测次数不同于前波，纵向分析需遵循指南建议采用等百分位等值分数，不能直接合并原始分。映射字段、实现及文件SHA1见[`hcap_wave4_cognition_bias_guidance_review_2026-10-22.md`](hcap_wave4_cognition_bias_guidance_review_2026-10-22.md)；已在认知条目页面附概念/题目级警示。
