# 医保与医疗利用字段：官方值标签及连续量审计

更新：2026-10-17。脚本 `scripts/enrich_healthcare_access_labels.py` 只读取公开变量映射和已归档的 CHARLS 问卷/代码本，不读取个人回答。

2026-10-23更新：本专项217条字段映射的逐字段`value_label_status`及官方来源现已同步到通用E/P目录与网站。即使没有离散值标签，连续次数、持续时间、金额/区间端点及编码/路由不确定性也会显示对应状态，不再统一落成“待逐项核验”。2011/2013保险未选值、特殊缺失、极值、实际分母和发行文件编码仍需在获准数据中验证；因此页面状态只记录问卷/代码本证据，不代表可直接分析。

## 本轮结果

目录有11个概念组、124条“概念—波次—源字段”映射。66条字段行录入了可明确支持的类别标签，37条连续计数/时长字段补充了量的含义与适用边界；另有21条早期多选保险字段明确保留“底层未选/否存储码待核”。2020疫情期间延误/未获照护字段另逐项记录`0=No`和该字段选项码`=Yes`，并提示条件分母。这些都是映射行，不是独立指标数。

已确认的类别标签包括：2011–2018门诊使用、过去一年住院发生，以及2015医保延续/核实题的`1=Yes, 2=No`；2018医保多选字段按逐字段代码本记录`0=No`及该计划类别代码的“Yes”；2020 BA017按问卷列出六种保险类别。2020代码本将BA017以数值型字段摘要呈现，字段取值标签仍应在允许访问的发布文件中复核，所以来源和审查状态明确标为“问卷类别已核、发布值标签待复核”。

2011/2013保险题为类别特定多选项，摘录的频数表不足以确认未选中/否的底层数值存储码；目录保留字段本身的计划标签，不猜0/1或把缺失当否。2015 EA001_W3_1、W3_2、W3_3分别是上波记录核实、当前是否仍持有预载保险、两次访问之间是否曾持有该计划，编码相同但题意不同，不能合并为一列当期保险状态。

连续量字段按题意展示：ED005为按机构槽位记录的门诊就诊次数；EE004为过去一年住院次数且受住院路由限制；EE016为最近一次住院的夜数，而非年度总夜数。代码本观察摘要中的EE004最大值差异很大（2011为2011、2018为150）；这些值只提示发布值/数据质量需要检查，不可作为有效范围或特殊码结论。个体级格式和特殊码须在获准本地发布文件中核验后再分析。

门诊`ed001`在2011–2018各波均为`1=Yes, 2=No`，但2018问句明确排除体检；门诊机构次数按各波不同回忆窗/路由记录。2011–2018医疗服务Part II禁止代理人代答。2020退出访谈字段不并入在世受访者常规医疗利用序列。2020主访谈DA009–DA012是COVID-19期间的延误/未获照护，不是常规医疗使用字段；DA010和DA012以DA009=Yes为路由条件，DA011进一步以延迟/未获得门诊服务为条件。逐项选择码不同于常见的统一0/1编码：字段后缀选项码代表Yes，0代表No。

## 页面与复现

本地医保/医疗利用页面现可搜索类别标签和连续量语义，并展示审查状态、代码本/问卷来源和题目边界。重建顺序：

```powershell
python scripts/build_healthcare_access_crosswalk.py
python scripts/enrich_healthcare_access_labels.py
```

CSV与`site-prototype/dist/healthcare_access_v1.json`同步生成。官方来源为`sources_official/CHARLS_2011_Codebook_extracted.txt`、2013/2015/2018/2020对应代码本、各波问卷；2020 BA017标签具体定位在`CHARLS_2020_Questionnaire_English_extracted.txt`第11页。

不输出受访者数据或推算的个体级汇总值，不建立跨波统一医保类别，不构造费用/利用衍生指标。
