# ExWAS 逐对可估计性审查记录模板（v1）

本模板用于**受控本地分析环境**，每个波次×暴露×表型×模型对比单独填写。不要把填写后的审查记录、响应者级记录、类别小单元计数、权重分布明细或可回推信息提交到GitHub或网站。公开结果表只保存经过披露审查许可的状态和审查引用。

## 资格与设计核对

对每项填写“通过 / 阻断 / 未解决”，并记录所依据的官方来源版本或受控QA记录编号。

- 发行文件、样本标记、字段身份及特殊缺失码已核对：
- 暴露、表型和协变量的问卷路由/模块资格已核对：
- 目标年龄域、配偶记录处理及波次总体定义已核对：
- 权重适用对象和非应答/子样本适用范围已核对：
- PSU、方差分层/复制权重及方差方法已核对：
- 域筛选在完整设计上实现，未先物理删除域外PSU：
- 逐对缺失与模型完整案例规则符合预注册定义：

若任何关键项目为“阻断”或“未解决”，不得把结果标为 `reviewed_pass`。

## 变量支持和拟合诊断

在受控环境查看必要诊断，填写结论和受控证据位置；精细数值不写入公开表。

- 连续暴露/表型：合法范围、特殊值、变换、零方差/近零变异和影响点已核查：
- 分类暴露/表型：所有实际使用类别、参考组、类别支持与加权分布已核查：
- 二分类表型：事件与非事件在模型所需类别/设计单元中的支持已核查：
- 完全/准完全分离及稀疏支持迹象已核查：
- 极端权重及其对估计/不确定性的影响已核查：
- 设计自由度、PSU信息、有效样本信息与模型参数复杂度已共同评估：
- 收敛、梯度/矩阵、标准误、区间和P值数值状态一致且可解释：
- 结局/暴露编码和系数尺度/对比方向经独立复核：
- 需要的敏感性分析或替代模型已完成，或已写明不适用理由：

以上项目是审查维度，不是自动阈值。不得根据本项目单个合成测试设定通用事件数或样本量门槛；任何数值规则必须在查看目标关联结果前预先确定，并有方法依据或专门模拟支持。
