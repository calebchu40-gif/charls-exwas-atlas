# CHARLS 客观体格与功能测量候选目录 v1

本目录把 CHARLS 2011/2013/2015 的现场体检模块归并为15个候选测量概念、45条波次映射。脚本为 `scripts/build_objective_measurement_crosswalk.py`，CSV为 `audit/objective_measurement_crosswalk_v1.csv`，本地原型JSON为 `site-prototype/dist/objective_measurements_v1.json`。

候选概念包括收缩压、舒张压、脉搏、呼气峰流速、握力、半串联/全串联/并排站立平衡、计时步行、重复椅子起立、身高、上臂长度、膝高、体重和腰围。它们是现场测量/功能测试表型，不是外界环境化学暴露。

## 编码与测量解释

原始代码目录显示各波的体检模块字段名大体沿用qa至qm序列，但题目和路由标签会有波次差异。血压和脉搏每人有重复读数；握力左右手各两次；呼气峰流速最多三次；平衡和步行也有完成状态、重复计时或代偿动作字段。映射表按概念把读数列放在一起，保留原始字段，不预先把均值、最大值或阈值定义成唯一标准。

需要特别注意：
- `qg002/qg003` 是行走计时；如需计算速度，必须根据对应问卷中的测试距离和单位推导。
- 呼气峰流速不能称作完整肺量计肺功能。
- 2015 `qh006` 是椅子测试所用椅子/座椅高度相关信息，不是个人身高；个人身高是 `qi002`。
- 完成状态、拒绝/无法测量原因、测量侧别、衣物/鞋履、地面和代偿动作属于资格或质量信息，不应无差别当作测量值。
- 局部字段变量名相同并不自动证明单位、测试协议或跨波量尺相同。公开前还需依据波次问卷和原始值标签逐项核对。

CHARLS 2011 Baseline User Guide 明确把血压、脉搏、峰流速、握力、起立、步行、平衡和人体测量列作非血液生物标志物；2013/2015官方 Biomarker Questionnaire 分别记录相应测量流程。此版本是代码与概念的候选crosswalk，尚未批准跨波合并，也未使用个体测量值。

### 椅子起立测量的座椅信息修正（2026-10-16）

变量目录在2011/2013仅将`qh006`标为“Height”，宽泛关键词规则因此曾将它误认为受访者身高/表型。官方代码本汇总值均约42–44 cm，且它位于重复椅子起立测试代码组；CHARLS 2015官方生物标志物问卷明确说明QH006记录椅面离地高度，标准CHARLS椅为42 cm，其他椅子的高度记入QH006_1。故2011/2013/2015 `qh006`及2015 `qh006_1`现归为C类“椅子测试座椅设置”测量元数据，不作暴露或表型；个人实测身高仍是`qi002`。逐波映射在`audit/measurement_protocol_crosswalk_v1.csv`，代码本统计摘要和2015问卷原题的来源与限制均保留；2011/2013原题措辞仍标注需进一步核对。
