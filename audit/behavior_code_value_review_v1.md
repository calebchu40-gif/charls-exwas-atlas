# 行为字段官方值标签审计（2026-10-16）

## 2026-10-23 目的字段补录

2015、2018、2020三波的体力活动目的字段（剧烈/中等/轻强度）现已按各自官方Codebook补录四类回答文字，共9条字段映射。只保留选项，不复制频数；目的类别不是活动发生、频率、时长或剂量。详见[`physical_activity_purpose_labels_2026-10-23.md`](physical_activity_purpose_labels_2026-10-23.md)。

依据 `sources_official/` 中2011、2013、2015、2018、2020官方代码本，为吸烟、饮酒和体力活动候选字段补入有来源的回答值标签。脚本 `scripts/enrich_behavior_value_labels.py` 在基础目录构建后运行；只读公开变量元数据与代码本，不读受访者记录。当前行为目录含23个候选概念、235条字段映射；166条映射有明确类别标签，另有32条映射标明为连续数量/时长字段（6条每日卷烟计数、10条睡眠/午睡、16条饮酒数量字段），不是分类代码。这些是映射行，不是独立指标数；尚未审计的其余字段不能视为已统一。

## 已加标签的字段组

- 吸烟状态：波次分别展示 `da059`/`da046` 的 `1=Yes, 2=No`；在适用波次展示当前吸烟/戒烟状态；2015 `da061`与`da061_w3`、2018 `da061_w4`、2020 `da047`有`3=Never smoked`这一额外类别。保留 `Smoke`、`Ever Smoked` 和返访者预载状态之间的问法差异，不只凭同名变量建立跨波ever/current定义。
- 烟草产品：代码本列明烟斗、自卷烟、过滤/未过滤卷烟、雪茄、水烟类别。2011/2018/2020是类别代码，2015为多选槽位。2011–2015的未选择字段存储值未一概验证，目录仅标出正向选项，不把空值当“否”。
- 每日卷烟数量：2011–2018 `da063`及2020 `da050_1/da050_2`按连续计数处理；2020区分当前和戒烟前日均数量。其极端值/特殊值、测量单位和适用路由仍须单独按正式数据格式审查。
- 近期饮酒频率：2011/2013/2015/2018 `da067`、2020 `da051`均为1=过去一年每月至少饮酒一次，2=饮酒但不到每月一次，3=无此类饮酒。该题是频率类别，不能改成简单的是/否而丢失类别含义。
- 既往饮酒频率：2011–2018 `da069`为1=从未饮酒，2=过去饮酒少于每月一次，3=过去饮酒多于每月一次；它不是只含“曾经/从未”的二元题。
- 饮酒类型：2018 `da068_s1–s3`代码本明确列出0=No及各酒类类别；2011/2013/2015的`da068s1–s3`展示每个多选项的正值代码，未选择码保留为待核，不由相邻题推定。
- 吸烟依赖：`da066`醒后首次吸烟为4级时间档。饮酒频率字段 `da072`、`da074`、`da076`（2011–2018）和 `da052`（2020）按酒类分别记录，类别为1=每月一次、2=每月2–3次、3=每周一次、4=每周2–3次、5=每周4–6次、6=每天一次、7=每天两次、8=每天超过两次。过去一年最近一次饮用量单独记录，不能与频率相加或据此换算纯酒精克数。
- 饮酒开始/停止时间的主选择题在2011–2018显示1=年份、2=年龄；主题和具体年份/年龄数值字段分列。

## 体力活动编码

- 2011–2018 `da051` 与2020 `da032` 是是否参加相应活动的二元题（1=Yes，2=No）。每个强度/活动项目单独保留，不把“无活动”或未走到该题的跳转缺失自动填为否。
- 2011–2018 `da052` 与2020 `da033` 记录过去一周活动天数；1–7是天数，不是频率等级。只有走到相应活动路由者会被问到。
- 时长为分档变量：2011–2018 `da053`为每周高强度活动小时档（<2/≥2小时）、`da054`为每周中等强度活动分钟档（<30/≥30分钟）、`da055`为每周步行小时档（<4/≥4小时）；2020对应字段为`da034`（高强度小时）、`da035`（中等强度分钟）、`da036`（轻度活动小时）。类别值相同不代表活动域相同。
- 2013/2015的活动模块存在抽样/问卷版本覆盖差异；同时2020用轻度活动替代早期问卷中的步行项目。应按官方问卷版本、路由和样本覆盖做跨波可比性判定，不能仅凭同为二分类码合并。

## 睡眠时长字段（连续值）

睡眠时长 `da049`（2011–2018）/`da030`（2020）是连续小时值，五轮问卷均问过去一个月夜间实际睡眠时间（每晚平均），量程标注为0–24小时。午睡 `da050`（2011–2018）/`da031`（2020）是过去一个月午餐后的连续分钟值；问卷明确不午睡记为0。2020问卷对两项都明确规定无法回答记为−1；代码本汇总值也观察到−1。2018午睡代码本摘要最大值为999，与问卷量程/上下文不一致，当前保留为异常待核，不擅自认定为拒答码、截尾值或有效时长。2011–2015及2018问卷条目与代码本标签相互印证；2013/2015代码本标签简略，但问卷题干与其余波次一致。各波题干行号和逐字段编码/语义已经写入`questionnaire_source`与`value_semantics`，网站展示官方问卷来源定位。睡眠题在随机抽样体力活动模块之前，不要把DA051起的活动子样本限制误套到DA049/DA050。

## 吸烟依赖题与饮酒数量

- 2011/2013 `da066`询问醒后多久吸第一支烟，代码为1=5分钟内、2=6–30分钟、3=31–60分钟、4=超过1小时。该题是有序时间档，不是吸烟量，也没有据此计算依赖量表分数。官方问卷行号已附在字段映射中。
- 目录将“饮酒频率”与“过去一年最近一次饮酒量”拆成两个独立暴露候选概念。频率包括各酒类的频率档和2020 `da052`；数量包括 `da073`、`da075_1/da075_2`、`da077`。`da075`只用于选择啤酒量以瓶或杯记录，属于计量单位选择元数据，不再列为暴露指标。问卷给出1两=50 ml、1瓶=2.5杯、1杯=220 ml。2020当前映射中只有饮酒频率字段，没有凭早期波次补造数量指标。
- 这些量题报告的是过去一年内最近一次饮酒，不能与频率直接相乘或折算成乙醇克数。部分官方代码本的数量最大值超出问卷提到的量程，例如2018葡萄酒量摘要最大值4380、烈酒量10950；2011–2015部分啤酒瓶数摘要也高于问卷写明的120瓶上限。将它们标作数据质量/特殊值待核，必须查发行文件的有效缺失码和底层变量格式后再分析，不猜其类别。
