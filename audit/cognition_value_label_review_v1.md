# 认知条目值标签核对（2026-10-16）

## 本轮核对范围

当前认知映射共341条字段、17个概念，其中255条已带官方类别标签或连续作答语义。值标签覆盖骤增主要来自逐词字段在不同波次采用的存储规则已按官方代码本编码；它不表示255个独立认知指标或255项已可跨波比较。

- 五波自评记忆：2011–2018 `dc004`、2020 `dc006`，有效类别1=Excellent至5=Poor；2020另列997=Don't Know。此题是主观记忆评价，不等于客观记忆任务得分。
- 2020时间定向`dc001`–`dc005`：1=Correct、2=Error、997=Don't Know、999=Refused。五题分问年份、季节、日期、星期、月份，项目不宜脱离题目直接合成可跨波定向总分。
- 2020连续减7：`dc007_1`至`dc007_5`是是否记录作答的状态变量（1=Record Answer、997=Don't Know、999=Refused）；对应`_1`数值字段是连续记录结果。代码本摘要有明显异常极值，只能提示检查数据和问卷，不能据此设定答案范围或自动计分。
- 2020`dc008`辅助工具使用：1=Used、2=Not Used；它描述施测条件，不是认知能力结果。
- 2020`dc009`画图：1=Correct、2=Error、3=Not Assessed、997=Don't Know、999=Refused。未评估必须与错误分开。
- 2018三物品学习与延迟回忆：代码本列出了球/旗/树/无/未评估分项字段；每个选项以`0=No`和匹配项编码表示，未评估为单独`97`标志。不得把某个词项字段里的0直接当成任务未作答，也不得把`97`改成错误。此处保留选项级编码，未求正确项目总数或跨轮学习分数。
- 2018手表/铅笔命名：`dc016_w4`、`dc017_w4`均为1=Correct、5=Error、97=Not Assessed；适用对象、未评估原因和扩展模块筛选仍需结合问卷路由审查。
- 词语即时与延迟回忆：按不同波次的官方存储结构分别标注。2011/2013/2015代码本把选中词项记录为词表位置码（如`n=Wordlist[n]`），11为None，2015另有12=Refuse to Recall；这些代码本没有证明未选择项存成0，因此不推断0=No。2018代码本为词项专属字段，0=No、对应词项码=选中，11=None、12=Refused to Recall。2020代码本中即时回忆`dc012`–`dc014`为0=No、1=Yes的词项复选框（具体词表位置在字段标签中）；`dc028`是延迟回忆，同样为0=No/1=Yes，11=None、12=Refused to Recall。2018和2020的项目选择/拒绝字段不应与答对/答错混为一谈。
- 2018概念分组修正：`dc028`–`dc030`是三轮即时词语回忆，`dc047`是延迟回忆，原“词语再认”组已拆回正确语义；`dc031`为施测条件，`dc032`–`dc039`为限时动物命名流畅性，`dc042`–`dc045`为CSI-D单题，均不属于词语回忆。原宽规则误纳入的`dc046`空气质量满意度已从认知组移除。

除2020明确列出的特殊码外，其他波次频数表未列出的特殊码均未推断为不存在；特殊/结构性缺失完整性仍待释放数据字典核查。

## 来源与复现

逐波对照`sources_official`下2011、2013、2015、2018、2020官方代码本和问卷。2020代码本相关项见印刷页213–215；2018扩展认知代码本见印刷页516–521，2018问卷说明DC028–030三轮即时回忆、动物命名流畅性、CSI-D及DC047延迟回忆。通过以下顺序重建后再附加已审值标签：

```powershell
python scripts/build_cognition_item_crosswalk.py
python scripts/enrich_cognition_value_labels.py
```

标签现展示于网站认知概念表，支持按原始码检索。其他认知字段仍需按变量类型区分类别、计数/连续作答、项目级多选答案、施测状态与特殊码，不能把槽位数量当作认知指标数量。2011–2015词表位置字段具体对应测试词表的词语顺序，页面保留`Wordlist[n]`原标签，不把索引误译为实际词语。


## 2018词语辨识值标签增补

`dc048_w4`–`dc067_w4`共20个词卡条目均按2018官方问卷和代码本标注1=Yes、5=No、8=Don’t Know。逐词识别反应不等于已计算的正确辨识分数；需要外部定义目标词/干扰词及计分算法后才能汇总。

2018 HCAP测验需附加官方偏倚及跨波可比性边界，详见`audit/hcap_wave4_cognition_bias_guidance_review_2026-10-22.md`；映射重建脚本现在会把这些警示写入认知概念/字段页面。

## 2026-10-22增补

依据官方HCAP Data Alert与User Guidance，认知crosswalk已补入`dc026_w4`及`dc026_w4_revised`，并在2018字段上展示具体测量偏倚和跨波比较警示。当前认知映射为344条字段/19个候选概念，其中258条有明确类别标签或连续语义；`dc026_w4`保留99=Other，`dc026_w4_revised`按Codebook列示类别，两者不计频数，修订规则未明前不得自行重算。完整边界见`audit/hcap_wave4_cognition_bias_guidance_review_2026-10-22.md`。
