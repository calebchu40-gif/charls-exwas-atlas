# CHARLS抽样权重与调查设计字段审阅 v1

日期：初稿2026-10-10；官方资料复核更新2026-10-22。范围：CHARLS 2011、2013、2015、2018、2020官方用户手册/发布说明和本地已整理个人表中可见的权重、样本标记与设计标识。个人级权重值只在 `%LOCALAPPDATA%` 的本地表中读取；项目内仅记录聚合人数、变量名和标签。

2026-10-24 对 Wave 2 官方发布说明补充了估计目标级权重解释：区分 `crosssection`/`longitudinal` 样本资格、含/不含非应答调整的横截面权重、纵向响应概率权重，以及独立横截面生物标志物权重；该波没有纵向生物标志物权重。执行限制和官方原文依据见[`wave2_weight_estimand_source_review_2026-10-24.md`](wave2_weight_estimand_source_review_2026-10-24.md)。

## 官方说明确认的使用边界

- CHARLS基线采用分层、多阶段PPS抽样，抽样单位包括县/区、村/居和家庭；基线调查的目标总体是45岁及以上、居住在家庭中的中老年人，养老机构人群不在基线抽样框内。官方建议作全国总体推断时使用样本权重。
- 2018 Wave 4用户手册说明提供横截面家户权重、个人权重，其中`INDV_weight_ad2`包含家户和个人非应答调整，`INDV_weight`不作非应答调整；使用`Sample_Infor.crosssection`识别横截面代表样本。官方从Wave 3起不再发布通用面板权重，因为面板权重依研究者选择的面板期数和失访处理而异。
- 2020 Wave 5用户手册作相同提醒：`INDV_weight_ad2`与`INDV_weight`为不同非应答调整口径；横截面权重覆盖代表性样本，其他访谈个体可能没有权重；`crosssection`用于识别横截面样本。2020 PSU信息与往期保持一致。
- 2015发布说明只发布该波横截面权重，并解释横截面样本与纵向样本不必相同；提供生物标志物权重，用生物标志物应答倾向模型调整个体横截面权重，逆概率因子在第99百分位截尾。不能把单波横截面权重直接当作任意多波面板权重。
- 2011基线用户手册区分家户、个体和生物标志物非应答权重；血样分析另有血液样本权重。2011/2013的权重字段命名和2015以后不完全相同，需在变量字典明确分析对象与权重。
- 年龄总体需按波次限定：2018 Wave 4 手册记载 2013、2015、2018 分别加入基线年龄 43–44、41–42、40 岁的预留刷新样本；2020 Wave 5 手册明确，刷新样本耗尽后 2018 年后较年轻队列不再具有全国代表性。因此 `crosssection` 标记及 Wave 5 横截面权重本身不足以支持“2020 代表所有 45+”的宣传或模型目标。详见[`wave_specific_target_population_and_age_coverage_2026-10-22.md`](wave_specific_target_population_and_age_coverage_2026-10-22.md)。

官方抽样指南说明村/城市社区为PSU；2013独立`PSU.dta`确有450个社区ID及省、市、NBS城乡和区域类型字段。2018/2020用户指南称PSU信息与前几波相同。既有`audit/charls_psu_mapping_aggregate_v1.csv`把官方2013 PSU映射与本地五波社区键做了聚合覆盖核验：各波观察到446–450个communityID；该历史聚合核验支持将`communityID`作为PSU候选，但重建后的源文件版本与键关系仍需再次确认。

**方差分层仍未解决。** 官方指南描述基线按地区、城乡县区和人均GDP排序形成隐式分层后抽样，但当前公开权重/PSU文件没有明确的方差`stratum ID`。`province`、`city`、`urban_nbs`、`areatype`是地理/抽样背景字段，不等同于官方方差分层编码。已在`survey_design_field_coverage_v1.csv`为各波增加`explicit_variance_stratum_id`缺口行；不从这些代理字段拼造分层，也不宣称只用PSU已完整反映分层设计。需要继续查官方是否发布方差估计专用建议或 replicate weights；若未提供，报告方差估计限制并采用明确标记的近似方案，方案在分析前预注册。

## 对本项目分析设计的决定

1. 单波横断面全国推断：先用官方样本标志（2011基线样本按基线定义；2013需重建以恢复丢失的旗标；2015–2020现有表含`crosssection`）确定代表性样本，再选与目标层级匹配的权重。普通访谈结局用个体横截面权重；生物标志物/血液化验须按官方说明和发行文件逐波确认专用权重覆盖的具体模块。
2. 若把活动随机半样本或血液/体测子样本作总体推断，须结合官方提供的子样本/生物标志物应答调整权重；不能只筛完人后复用一般个人权重而不讨论非应答与子样本选择。
3. 多波重复测量/纵向估计不能把每波横截面权重拼接后当成通用纵向权重。须先定义入组队列、完整/非平衡面板和目标总体，再用透明的失访/死亡处理构造或选择纵向权重，并做敏感性分析。
4. `communityID`是已确认的PSU标识，可在适用设计加权模型中表示社区内聚类；但只有PSU和权重、没有官方方差分层ID时，方差估计不完整。关联图谱须标明目标样本、权重、分析N和方差限制，不把地理背景字段伪装成分层变量。

## 随机活动子样本的补充审计

CHARLS官方 Harmonized CHARLS D 代码本说明，Wave 1–3 的身体活动题只对随机抽取的约半数样本询问，Wave 4 起询问所有受访者；题项并非加速度计测量，且各波时间题/分类仍要逐题核对。([官方 Harmonized CHARLS D Codebook](https://charls.pku.edu.cn/en/team/Codebook.pdf)) 本地准备表聚合审计见`activity_subsample_aggregate_v1.csv`：任一活动字段非空数为2011 6,918、2013 6,092、2015 9,855、2018 19,732、2020 19,353。2013和2015均存在`da051_random`（标签`Ca052Random`），但其代码与答题关系跨波不一致；审计保留代码原值，未推断代码含义。2011表中没有发现该字段。

因此，随机子样本设计已由官方资料确认，但每个波次的抽选标记/实际应答路由及活动模块专用非应答调整尚未确认。普通个体横截面权重有正值只表示该记录有普通权重；不能据此声称它已处理活动模块随机入样或模块无应答。下一步须逐波对照原始问卷与发布代码本，再决定2011–2015活动模块的合格样本标记、分析权重和方差估计；2018/2020可先按全体受访者题项候选处理，但仍须保留题项有效性、活动时长可比性和横截面样本权重限制。

## Harmonized CHARLS 官方代码本在线复核（2026-10-16）

CHARLS 当前公开的 [Harmonized CHARLS Codebook](https://charls.pku.edu.cn/en/team/Codebook.pdf)（828页）明确说明：其变量可用于加权估计及 CHARLS 提供设计信息时的设计调整标准误；手册列出个人横截面权重、2011–2015生物标志物权重和有限波次纵向权重，并说明抽样为按城乡地区人均 GDP 分层、县/区—村/社区—家庭多阶段 PPS。手册也确认行政村/城市社区为 PSU，并将可识别的主要受访者限定为家庭居住人口，基线总体为45岁及以上。手册对缺失原因还区分普通缺失、年龄不合格、不知道、拒绝、跳题、无子女、不适用、未婚/配偶未访等，支持本项目将结构性缺失与普通缺失分开记录。

这项复核收窄了此前“方差设计信息仍待查”的含义：**分层抽样方法本身已有官方说明；待闭环的是本项目当前五波源表/Harmonized D 版本中可直接用于软件方差估计的逐波分层标识或官方 replicate-weight/方差实现，以及它与2018/2020更新版本的兼容性。**2013官方波次资料页确实分别发布 PSU 与 Weights 文件；2018手册说明 PSU 信息与先前波次相同。Harmonized CHARLS Codebook说明其变量可支持“CHARLS提供设计信息时”的设计调整标准误，但权重章节未给出可直接用于软件方差估计的方差分层变量名，也未说明复制权重。检索这些公开页面和手册未发现此类字段/说明；这只表示当前公开文档审阅未确认，不能推断CHARLS从未提供或不提供。应针对本项目准确使用的官方版本，对照全部下载的 `PSU`、`Weights`、`Sample_Info` 文件变量清单和标签逐项核验；如仍没有公开可用方差层/复制权重，应向CHARLS官方数据支持渠道询问。核验完成前仍不可把 province/city 等地理字段自行当作分层标识。

### 2026-10-22官方方差设计复核与分析决策

本次重新检查了官方 Harmonized CHARLS Codebook、2013波次资料页、2018用户手册和官方抽样介绍。官方资料能支持以下事实：社区/行政村为PSU；各轮有相应个人横截面权重，部分波次/测量另有生物标志物权重；抽样过程按城乡地区人均GDP分层，并采用县区—村/社区—家庭多阶段PPS。2018手册明确横截面权重及`Sample_Infor.crosssection`，并称PSU信息与以往一致。2013资料页将PSU和Weights作为独立公开文件列出。

当前资料**不能支持**将`province`、`city`、`urban_nbs`或`areatype`直接当作官方方差层；这些是地区/城乡信息，不是经核实的原始隐式分层排序ID。也不能把只有权重和PSU的Taylor线性化标准误称为完整复现了分层设计。调查统计通行做法需要权重、第一阶段方差层（或经设计方说明的伪层）和PSU，或设计方提供的复制权重；此处是统计方法学依据，不是CHARLS专属指令（可参见联合国抽样误差手册关于设计变量的说明）。

因此本项目执行顺序为：

1. 将本地实际官方文件的版本、变量名、标签、可链接键与跨波覆盖作元数据核验，不导出个人级值；确认是否有官方分层、有限总体修正或复制权重。
2. 正式关联估计前锁定目标总体和权重（普通问卷、实验室/血液或模块子样本分别处理），逐波限制相应横截面代表样本。
3. 若官方公开资料仍只支持权重与PSU，主分析采用明确声明的有放回PSU聚类线性化近似；标准误/区间标为“未纳入官方隐式分层的近似设计方差”，并报告敏感性分析。单波全国加权点估计与近似方差须分开解释。若官方明确禁止或提供其他指定做法，则按其要求修订；不虚构方差层。
4. 以未加权、仅PSU聚类、可确认完整设计的结果并列敏感性检查（仅在最后一项完整设计确有官方字段时）；不以普通独立同分布标准误作为主结果。

CHARLS来源：[官方抽样设计介绍](https://charls.pku.edu.cn/en/About/Sample.htm)、[2013 Wave 2资料页（PSU与Weights文件）](https://charls.pku.edu.cn/en/Data/a2013_CHARLS_Wave2.htm)、[2018 Wave 4 User's Guide](https://charls.pku.edu.cn/en/data/User2018.pdf)、[Harmonized CHARLS Codebook权重与设计章节](https://charls.pku.edu.cn/en/team/Codebook.pdf)。调查方差变量一般要求的说明见[联合国抽样误差估计手册](https://unstats.un.org/unsd/demographic/sources/surveys/handbook23june05.pdf)。

没有运行任何加权或未加权暴露—结局回归。已确认社区PSU键及跨波匹配；仍未解决公开方差分层变量/复制权重是否可用、血样/体测权重覆盖范围、以及2020疫情期测量方式的估计目标。这些是正式ExWAS之前的设计确认项，不妨碍继续扩展变量字典和缺失/样本审计。

## 2026-10-23 私有派生表样本标记与权重覆盖复核

在用户本机隔离目录的五波派生个人表上运行`validate_prepared_wave_tables.py`，只导出行数、列数、ID完整性、文件哈希和状态；五波均无缺失ID或重复ID，波次值与文件名一致。该验证不检查个人答案，也不等于模型就绪。

聚合核对派生表内的官方`crosssection`标记和个体权重覆盖：2015有20,279/21,095条记录标记为横截面样本，且恰好20,279条记录有正的`INDV_weight`；2018为17,970/19,816且权重覆盖一致；2020为17,364/19,395且权重覆盖一致。2020表中另有2,031条`crosssection=0`记录没有普通个体横截面权重，先前89.5%的权重合并比例由样本标记解释，不应误报为普通权重文件漏合并。2011表中17,705条记录均有正的个体权重，但该派生表不含独立横截面标记，不能据此推断所有分析题项的目标分母。

**2013仍需阻断。**18,605条派生记录中只有18,256条有正的`INDV_weight`；现存派生表缺少`crosssection`与`longitudinal`两个样本资格标记。CHARLS官方[2013 Wave 2资料页](https://charls.charlsdata.com/pages/Data/2013-charls-wave2/en.html)将Weights作为单独数据文件列出，SHA1为`22c4fc89df2e55fa8faf051e88830eebe0e035c0`；官方[Wave 2 Release Note](https://charls.pku.edu.cn/en/data/Release2013.pdf)明确说明该文件含cross-section和longitudinal资格标记。当前准备脚本已要求2013官方Weights来源必须包含这两个字段并把它们合入个人表，但现有派生文件是旧版本；加强后的验证脚本现在将2013标为`CHECK`，不再将五波误报为全部通过。当前已核验的本机私有目录只有派生表、没有可重建的2013原始源包；官方权重下载入口会跳转到[CHARLS登录页](https://charls.charlsdata.com/users/sign_in/en.html)，因此需在获准账号下重新取得官方Wave 2权重文件后重建。暂不臆测349条权重缺失的原因，也不依据普通权重非缺失替代官方样本标记。
