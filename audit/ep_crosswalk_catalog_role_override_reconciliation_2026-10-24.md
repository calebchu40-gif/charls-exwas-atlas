# E/P concept-source index reconciliation for explicit catalog role overrides

Updated 2026-10-24. The field catalogue already applies `audit/catalog_role_override_review_v1.csv`, but the concept-source crosswalk builder previously retained seven 2018 `HA004` total-value/unit-value format selectors as E-role mappings. The official role audit classifies these selectors as C-only measurement/response-format metadata, and the main field catalogue contains the corresponding C records. Keeping them as E mappings inflated the exposure concept inventory and could make a non-exposure selector appear in concept-pair metadata.

`build_ep_concept_source_crosswalk.py` now reconciles a source mapping to C only when (1) an exact wave/code/old-role entry explicitly sets `keep_role=C`, (2) the mapped concept matches the reviewed concept ID when one is specified, and (3) the exact source module/code exists in the candidate catalogue as C. It retains the original mapping provenance, appends the role-review source and rationale, and leaves unrelated E/P rows unchanged. The seven `ha004_w4_[1-7]_` format selectors are now C and match their C catalogue entries. A second reconciliation step prevents specialist concept joins from repopulating an E/P candidate ID on these C-only field-catalogue rows. Their paired amount fields (total price and unit-area price) remain separate household-property candidates.

This correction changes only candidate role bookkeeping; it does not use respondent records or summary statistics and does not alter the formal analysis-lock inventory. Regression tests verify all seven exact codes are C-only, matched to catalogue metadata, and have no candidate concept ID in the E/P field catalogue. Full finalization completed: 1,428 unique E/P candidate concepts (1,149 exposure concepts and 288 phenotype concepts, including 9 dual-role concepts), 6,624 source mappings, and 89 formal analysis locks. The static catalogue contains 4,750 E, 2,110 P, and 978 C field-wave rows. Per-wave metadata co-availability counts are 121,107 (2011), 126,514 (2013), 130,376 (2015), 101,551 (2018), and 13,906 (2020); these are not sample sizes, eligible association counts, or results. The complete test suite has 210 passing tests; 34 static JSON files, JavaScript syntax, Python compilation, and `git diff --check` pass. No association models or pairwise complete-case sample sizes have been computed.

Source of the role decision: `audit/catalog_role_override_review_v1.csv` (2018 `ha004_w4_1_` through `ha004_w4_7_`); official measurement and value-field review: `audit/household_property_value_2018_slot_unit_review_2026-10-23.md`.
