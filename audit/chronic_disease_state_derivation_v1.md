# CHARLS 慢病逐波状态派生规则 v1（暂定）

日期：2026-10-10。此规则用于准备后续 ExWAS 候选结局；它不是临床诊断，也不是 CHARLS 官方发布的 harmonized outcome。主概念为“受访者自报曾被医生诊断”。状态仅取 `1=是`、`0=否`、缺失=未能判定；另存逐病冲突标记与来源。

## 逐波规则

| 波次 | 判定规则 | 保留冲突/未知的情形 |
|---|---|---|
| 2011 | `DA007[i]=1/2` 分别记为 1/0；其他或空值为未知。 | 基线没有上一轮状态可用于补齐。 |
| 2013、2015 | `XRType=NEWIW(1)` 用当轮 `DA007[i]`。`REIW(2)` 先取同一 ID 前一可用波次状态；不能直接联结时用问卷预加载 `ZDA007/ZDA008`。返访记录没有阳性预加载且没有既往阳性联结时，按问卷显示“有/无上一轮记录”的阴性分支作为既往无诊断。区间新诊断题 `DA007_W2_2=1` 判为有；上一轮状态核实同意且既往有病判为有；既往无病、核实同意且区间新诊断为否判为无。核实不同意且区间无新诊断时，按被纠正的旧记录反转上一轮状态，并标冲突；若否认既往无病记录且报告可用首次诊断年份/年龄，则判为有并标冲突。 | 返访核实不同意但诊断时间缺失、关键分支缺答或既往信息不可用时保留未知/冲突。`DA009` 年份仅接受 1900 至当前波次的值，年龄仅接受 1–120。 |
| 2018 | 本轮 `DA007[i]=1/2` 直接记为 1/0。若原题未答、既往状态为有且 `DA010_W2_2[i]` 不是 99，则携带既往“曾诊断”状态。若病程题为 99（从未有过）而原题缺答，则记 0；与既往有病相矛盾时标冲突。 | 既往无病而本轮相关题均缺答时为未知。既往有病但本轮回答否时以本轮自报为当前状态并标冲突。 |
| 2020 | `DA003[i]=1/2` 直接记为 1/0。原题缺答时，只有既往有病且病程题 `DA002[i]` 不为 99 才携带既往阳性；`DA002=99` 表示上轮没有该病，不能单独推出本轮为否。 | 既往阳性而本轮直接回答否时以本轮回答记 0、标冲突；病程题与既往预加载相矛盾且本轮原题缺答时保留未知并标冲突。 |

## 解释和限制

- 2013/2015 `XRType` 编码与 2018/2020 相反；代码逐波显式处理，不能跨波复用同一数值映射。
- 2013/2015 返访者的“不同意上一轮记录”需用区间诊断和首次诊断时间识别旧记录纠正。首次诊断年份/年龄可证明曾有诊断，但日期逻辑仍需要按原始问卷分支做抽样个案级验证；所以当前产物标为暂定。
- “空白预加载=上一轮无病”仅在返访者分支使用；这是基于官方问卷“显示有/无上一轮回答”的解释。后续须检查各轮 codebook 对结构性空值和访谈缺失的区分，再锁定正式规则。
- 2018/2020 的既往状态先按同一 ID 的本项目已派生波次回溯，官方预加载只作兜底。2011 与 Harmonized CHARLS D 的 ID 格式未能简单匹配，因此没有做 ID 变换或借外部 harmonization 强行补配。
- `n_conflict` 是冲突标志人数，不是需要自动剔除的人数；主分析/敏感性分析如何纳入，须在分析方案阶段预先定义。
- 输出尚未用于回归、配对可用性更新或网站展示。所有个人级派生 DTA 仅保存在 `%LOCALAPPDATA%\\CHARLS_ExWAS_Atlas\\derived_chronic_disease`；项目目录只存放不含个人值的聚合摘要与代码。

## 合成规则验证

已覆盖基线明确是/否、新入样直接回答、返访区间新诊断、已确认旧诊断、旧记录纠正、既往无病但报告首次诊断时间、2018“从未有过”、2020与既往冲突等案例。验证生产输出时还要求：每波 8 个疾病，状态域限于 0/1/缺失；输出 respondent 行数及 ID 集合与本地准备表相同；每一行波次×疾病的有/无/未知数之和等于当轮 respondent 行数。
