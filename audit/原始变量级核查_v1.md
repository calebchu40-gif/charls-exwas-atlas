# CHARLS 原始变量级核查 v1

核查日期：2026-10-10  
范围：上传的 2011、2013、2015、2018、2020 原始波次发布包，以及 Harmonized CHARLS C/D 的 Stata 元数据（变量名、变量标签、模块行列数）。脚本临时解压归档并只读 DTA 元数据；未导出个体记录、未做关联分析、未上传任何微观数据。

## 产物与可复现方式

- `raw_variable_catalog_v1.csv`：39,234 条变量—模块—波次元数据记录，含变量名、英文标签、所在模块、该模块行列数和来源文件。
- `raw_archive_module_summary.json`：归档 SHA-1、完整性结果及 DTA 模块数。
- `candidate_variable_shortlist_v1.csv`：按初步关键词规则筛出的候选变量（881 条变量—波次条目）。
- `candidate_domain_counts_v1.csv`：关键词短名单的域级计数。
- `../scripts/build_raw_variable_catalog.py` 和 `../scripts/build_candidate_variable_shortlist.py`：元数据目录与候选短名单脚本。

运行方式（在项目目录）：

```powershell
python scripts/build_raw_variable_catalog.py --root "<上传数据根目录>" --out "audit/raw_variable_catalog_v1.csv"
python scripts/build_candidate_variable_shortlist.py
```

第一条命令里的数据根目录指包含 `原始数据+问卷2011~2020` 子目录的那个目录。归档解压写入系统临时目录并自动清理；输出只含元数据。

## 对“暴露—结局”的建议分类

不要把 CHARLS 说成化学暴露组测量项目。它的可行版本更准确是“社会、行为、家庭/社区环境与生物标志物—健康表型关联图谱”。暴露侧可按证据分层：

1. **直接测量生物标志物**：2011血样（未来若拿到独立2015血样，可扩到第二轮）；同时作为结局侧的代谢/炎症/肾功能表型时，应避免同一变量在同一配对里逻辑重复。
2. **个体行为**：吸烟、饮酒、身体活动、睡眠及可可靠提取的饮食项目；每一题需映射到统一定义并保留原始问卷版本。
3. **家庭环境代理**：燃料、饮水、卫生设施、住房条件等；通常是分类暴露，不要人为换算成环境浓度。
4. **社会与生命历程代理**：教育、职业、收入、迁移/童年经历（需补2014 Life History）；建议分层展示，避免把社会经济地位直接包装成污染暴露。

结局侧候选包括自报慢病、血压/人体测量、血液生化、身体功能、认知、抑郁/心理健康、睡眠及死亡/退出等。第一版可以采用“同一波次横断面”配对并逐配对标出可用样本数与缺失；纵向关联另建明确的滞后/重复测量分析，不把波次堆叠后当独立观察。

## 权重与样本代表性的官方提示

已核读随 2020 数据发布的中文《用户手册》第5节（PDF第21页）和第6节（第23页）：官方建议总体推断使用权重；2020 横断面家户/个体权重由第5轮抽样概率构建，区分是否对无应答调整，权重考虑死亡和离婚；从第三期开始不再发布统一面板权重，因为纵向权重取决于所选面板/波次，应由研究者按研究样本损耗方案构建。横断面权重只适用于代表性样本，`Sample_Infor.crosssection` 用于识别横断面样本；非代表性样本没有权重。该手册还说明 2020 发布中 PSU 信息与往期相同，但仍应按具体分析样本与官方设计文件核对。

因此不能把“每个指标直接套一个相同权重”作为全站模型规则。每个指标/配对必须声明分析样本（代表性横断面、血检子样本、跨波纵向队列）、对应权重、PSU/分层设计变量是否可用及缺失处理。2011血样应使用生物标志物权重；2020 官方横断面权重不能替代自定义纵向失访权重。分析若只定位为关联探索，仍需清晰披露权重目标总体；未加权结果可以作为不同 estimand 的敏感性结果，不能误称为全国总体估计。

## 计数解释和下一步

881 条是宽松关键词检索结果，包含重复波次条目、长表展开题项及明显误匹配；它**不是**最终暴露或结局指标数。需要在官方 codebook/questionnaire 基础上逐条复核题意、值标签、缺失编码、单位、调查对象、波次、抽样子样本与派生规则，之后才能给出可发表的有效指标数。Harmonized D 作为跨波 crosswalk 辅助；不能取代原始变量，C 与 D 不混用。

建议下一阶段先完成人工可审查的 v2 字典：为每个候选指标指定唯一概念 ID、角色（暴露/结局/协变量/设计变量）、各波原始名、原题/操作定义、编码/单位、来源位置、可比级别（完全/可转换/不可比/待核）和可用子样本。优先把短名单收窄为核心域，随后按波次执行同波可用性与有效 N 审计；社区暴露、2015血样和生命史单列为数据补齐/权限事项。
