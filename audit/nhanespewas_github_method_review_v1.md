## 代码和平台的总体逻辑

仓库 README 将图谱描述为 NHANES 1999–2017 十个调查周期中 305 个表型与 619 个暴露/行为的超过十万项关联；每个周期分别估计暴露—表型关系，再总结各周期效应，并考察 FDR、调整方案稳健性及周期间一致性。代码包提供复用 NHANES 预处理 SQLite 数据库的 R 接口；数据库变量目录同时记录变量标签、单位、类别和周期可用性。浏览器是汇总结果的查询界面，`nhanespewas` 则是变量配对、建模和输出结果的可复用实现。

## 已核对的协变量处理

NHANES 默认调整表覆盖年龄（另含年龄平方）、性别、收入贫困比、教育类别和种族/族裔。它额外为饮食回顾加总能量，为非尿结局的尿暴露加尿肌酐；另提供仅年龄、仅性别、年龄+性别、收入+教育等多个场景用于比较。周期因子可在部分调整场景中追加。这说明作者并非只用一个“全变量模型”，而是展示模型规格的稳健性。

论文主结果的完整人口学模型还包括调查年（类别变量），并报告年龄、年龄平方、性别、收入、族裔、教育、年份等不同组合的九种模型。连续暴露和表型按标准差缩放，分类暴露使用预设参考组；模型对每个变量对做完整案例分析。论文采用 Bonferroni 家族错误率阈值约 `4×10^-7`，并报告 Benjamini–Yekutieli FDR `<5%`；文章给出的 5% BY-FDR 对应 P 值约 `5.1×10^-4`。这些多重检验范围是全图谱级别的统计设计，CHARLS 需先定义检验家族再实施。

迁移到 CHARLS 时，建议先设定：主模型（年龄、性别及预先指定的最小混杂集）、扩展人口社会经济模型（教育、婚姻、城乡/地区、收入或资产等，须避免高度共线/过度调整）、领域特异模型（例如饮食相关总能量；尿/血生物标志物的稀释或检测因素，前提是 CHARLS 有合适变量和依据）。主模型的协变量集合仍需结合每个暴露—结局问题和时间顺序审核。不要把潜在中介（如 BMI、慢病、行为）机械纳入所有模型。

## 适用于 CHARLS 的流程草案

1. **数据目录与跨波次映射**：先建长表式 variable catalog 和概念 crosswalk，记录 2011/2013/2015/2018/2020 的原始问卷、体检、血检字段、单位、值域、适用人群和是否可比。把“问卷没有问”“因跳题不适用”“模块抽样未入选”“拒答/不知道”“数据缺失”区分开。
2. **形成候选对和逐对样本量**：每对保留各波次可用性、符合模块资格的人数、暴露和结局完整人数、纳入权重后人数及排除原因。PAIR N 是字段非缺失交集，不等于正式分析 N。
3. **波次特异分析**：每轮先独立估计，正确使用该轮对应样本的权重和抽样设计信息；若官方没有适配某模块/生物标志物子样本的权重/PSU/分层说明，应标记估计目标与限制，不能臆造设计变量。
4. **统一变换协议**：变量目录显式指定连续/有序/二分类/多分类/计数/检测下限；连续指标按需要预先指定原始尺度、对数或标准差单位效应，分位数组边界及参考组要固定并留档。结局类型决定线性、logistic、计数等模型；不是把所有表型都按同一线性模型处理。
5. **多重检验与稳健性**：为每轮和全图谱明确定义检验家族、FDR 校正范围、主/扩展模型、可比波次重复性和样本量门槛。结果记录估计值、SE/区间、P/FDR、N、权重/设计、模型方案、变换、软件和版本、收敛/失败状态。
6. **数据库/网站发布**：发布变量元数据和汇总统计；查询界面能过滤概念、波次、模型、样本量和可比性，并显示效应方向/单位、FDR 和定义说明。数据处理代码可公开，受限 CHARLS 原始记录不随网页或代码仓库上传。

## CHARLS 特别注意：2013/2015 慢病状态

本项目已有的变量审计发现，2013/2015 的 `DA007_*` 新诊断题存在进入条件：部分返访者不重复回答同一新诊断题，而通过既往病史验证及随访期间新诊断字段延续状态。因此不能把 `DA007_*` 的非空个数当作全波次患病人数，也不能简单把空白映射为“无病”。本地 Harmonized CHARLS D `.do` 提供了跨波次 chronic condition 派生状态和冲突/争议标记，可作为对照实现；应逐段核对原始跳题定义，保留不确定/争议状态，不能把 Harmonized D 当作官方原始数据或不加检查地当作金标准。2020 疾病清单字段映射也需单独核对。

另外，已有概念审计指出 CHARLS 2013/2015 身体活动模块为随机抽取约一半家庭，需将这类子样本缺失与普通缺访区分；当前在手的血液化验主要集中于 2011，腰围可用范围也不等同于所有波次。网站应允许“只在部分波次存在”的变量进入目录，而不是要求每个字段覆盖所有波次。

## 论文与代码仓库的一致性核对

不能只看 GitHub README 或单个脚本来声称复现论文。论文发表版本的方法部分报告八个 NHANES cohort samples/1999–2018 的主结果、survey-weighted linear regression、主人口学调整和其他八种比较模型、连续变量标准差缩放、全检验集 Bonferroni 与 BY-FDR，以及跨独立周期的 UWLS 汇总。仓库 README 的概述仍写 1999–2017/十周期；该 checkout 中批处理文件 `pipeline/pe_meta_adj.R` 使用 REML，而 `R/meta.R` 虽定义 UWLS 函数，却未被该分析脚本调用。说明仓库中有可借鉴的组件，但其静态快照未必等于论文最终生产流程；正式复现须结合论文补充方法/补充表、figshare 汇总字段和实际运行版本审计。CHARLS 项目将按“论文方法、GitHub 当前实现、CHARLS 新设计”三栏分别追踪。
