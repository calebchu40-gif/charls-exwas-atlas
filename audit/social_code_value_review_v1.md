# 社交参与与家庭联系：编码和值标签审计

本文件补充 `social_exposure_crosswalk_v1.csv` 的代码含义与可比性边界。它只总结官方代码本字段元数据，不含受访者记录或统计分析结果。

## 已核验的值语义

- 2018 `da056_s1` 示例：`0=No`，`1=Interacted With Friends`；`da056_s2` 同样以 `0=No` 和具体活动编码区分。
- 2018 `da057_1_` 活动频率示例：`1=Almost Daily`、`2=Almost Every Week`、`3=Not Regularly`。该题的方括号序号是活动槽位，必须与该受访者活动条目的排列/路由对应，不能把 `da057_1_` 固定解释为朋友交往频率。
- 2020 `xsoctype_*` 字段在2020官方代码本中标注为字符串变量。需按官方问卷定义解析实际字符串答案；不能假定与2018数值指示字段编码相同。
- 2013/2015代码本可见 `da056s*` 多选活动槽位标签（例如 `da056s1` 为与朋友互动、`da056s10` 为上网）；但不同年份代码本对活动题的存储/值标签呈现方式不一，正式重编码前需逐波确认原始变量类型、未选中/结构缺失表示和活动频率槽位联结。
- 2018 `cd004_1_` 子女联系频率示例包含“几乎每天、每周2–3次、每周一次、每两周一次、每月一次、每三个月一次、每半年一次”等类别。顺序频率属于类别，不应当作等距连续数值直接线性建模。

## 暂缓统一的内容

父母名册和家庭联系题的全部特殊码；cd002父母亲属范围随波次变化；子女/父母索引槽位、同住/非同住路由；缺失、不适用和未回答的区分；活动频率槽位和活动条目的链接；2020字符串活动项的规范解析。上述内容确认前保留波次字段，不生成社会参与总分、孤独/隔离阈值或跨波趋势变量。

从2011、2013、2015、2018官方代码本补齐三组社交字段值标签，共150条字段映射：社交活动频率44条、子女探访频率56条、子女联系频率50条。子女频率代码为1=Almost every day、2=2–3 times a week、3=Once a week、4=Every two weeks、5=Once a month、6=Once every three months、7=Once every six months、8=Once a year、9=Almost never、10=Other；保留有序类别，不按等距连续变量处理。活动频率代码均为1=Almost daily、2=Almost every week、3=Less often/Not regularly；2011代码本按固定活动类型分别提问，2013–2018则按DA056中受访者选择的活动顺序记录频率，后缀序号不能跨波直接解释成同一活动。

网页对这些150行显示官方代码本值标签，并在2011与后续波次之间保留活动频率槽位结构差异。其他父母名册字段、活动清单中的未选中/特殊缺失存储码仍未逐值核完；2020活动字段是字符串类别。未把这些项目重编码为跨波总分或二元无活动指标。官方摘录在`sources_official/CHARLS_2011_Codebook_extracted.txt`及2013/2015/2018对应代码本。
