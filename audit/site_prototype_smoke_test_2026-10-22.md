# 本地网站原型烟测（2026-10-22）

在本地 HTTP 预览中检查首页、E Catalog、P Catalog、C类测量/设计元数据、关联总览和血液生物标志物页。首页和 `catalog.json` 均返回 HTTP 200；网站字段目录加载7,868条波次字段记录。

首次浏览器检查发现 E/C 目录渲染失败：前端将有句点的属性名 `Review.Flag` 写成 `x.Review.Flag`，把字段字面值误当作嵌套对象。已改为 `x['Review.Flag']`，并将前端资源版本号从 `v44` 更新为 `v45` 以避免浏览器复用旧脚本。

复测结果：E目录载入且按 `blood_wbc` 搜索命中1条；P目录载入；C类目录载入672条字段记录；关联总览标明“尚无关联结果”及已拟合模型数0；血检页显示35条波次字段映射、16个实验室分析物概念，并将2015独立血检模块清楚标成当前本地缺少文件。页面无“载入失败”提示。`node --check site-prototype/dist/app.js` 通过。

可复现：项目根目录启动 `python -m http.server 8787 --bind 127.0.0.1 --directory site-prototype/dist` 后访问本机地址；浏览器搜索 E目录中的 `blood_wbc`，再检查P、C、关联和血检面板。没有个体数据请求或模型运算。
