# Chronic-disease self-awareness response labels, 2013–2018

Date: 2026-10-23

Official wave questionnaires confirm the DA008 response options `1=Yes; 2=No; 3=Don't know` for the disease self-awareness items in 2013 (DA008 indices 1, 2, 5, 6, 11), 2015 (indices 1, 5, 11), and 2018 (indices 1, 5, 11). The Codebooks contain frequency tables for these fields, but those counts are not copied into the public catalog. In sparse tables, such as 2013 DA008 indices 2 and 6, the observed-category list alone is incomplete; the questionnaire is the source for the full response menu.

These fields ask whether respondents know that they have the indexed disease. They are not physician-diagnosis indicators or disease prevalence measures. The disease index, prior-wave preload, interview type, and conditional question route remain wave-specific; release coding and eligible denominators require validation before analysis.

Validation: the complete metadata finalization pipeline ran, all 68 unit tests passed, and the public catalog contains one matching row for each of the 11 wave-field pairs. No frequencies or respondent records were used.
