## 为什么不能直接对标 NHANES 的 619/305

NHANES PE Atlas 的 619 暴露与 305 表型是论文定义后的分析目录。这里的 505 是跨波候选概念，3,879 是概念—源字段映射，7,280 是包含全部角色的目录行；三者口径不同。CHARLS本身有数百个问卷及测量概念，但没有NHANES规模的连续生物监测、尿液化学物、持久性污染物和环境采样体系。CHARLS更突出的内容是行为、家庭/社区环境、社会经济、慢病、功能和认知；血液实验室指标目前主要在2011与2015两波。

计数应分开报告：源字段、概念、跨波可比分析变量。拆分的词项、多个答案槽、家庭成员重复槽位、金额区间边界、血压/握力重复读数、题目分支和跨波版本不能不经定义就算成独立指标。

## CHARLS编码能否像 NHANES 一样检索

可以建立类似的查找体验。CHARLS字段按“波次 + 模块 + 原字段码”唯一识别；每条应连接官方字段标签、题目/测量定义、响应/测量单位、值标签、跳题和特殊码、适用样本及来源文件。比如2018 `Cognition::dc048_w4` 是词语辨识任务中的Church词卡，代码本响应为1=Yes、5=No、8=Don't Know；它只属于2018，且进入任务有路由条件。不能只凭变量名跨波合并，也不能把回答编码直接解释成对错或总分。

CHARLS与NHANES编码体系各自独立，不能复制NHANES的变量ID或按相似英文名判定测量等价。网站应提供CHARLS自身的逐波编码查询，并把经审核的概念映射与尚待核验的自动候选分层展示。

2011问卷纠正：原本地文件`CHARLS_2011_Baseline_Questionnaire_official.pdf`实际是2013追访问卷；现已从CHARLS官方2011基线页面取得正确DOC版基线家户问卷，并对癌症部位、残疾/起始年份、医保/医疗利用、家庭食品支出和访员观察住房项更新了来源。旧PDF的2011页码和任何依赖其内容的结论均作废。详见`sources_official/SOURCES.md`及领域审计报告。

## 当前已整理的客观测量和血检例子

- 现场测量：血压/脉搏、肺功能、握力、步速/平衡、坐站、身高体重腰围等。重复读数需按官方协议制定派生规则。
- 实验室指标：2011与2015各有16项候选分析物（共32条波次字段映射），包括血常规、血脂、糖代谢、肾功能和CRP。2015血检是单独发布的数据文件；当前目录只有官方发布说明，需取得对应官方数据后才能完成值域、缺失、样本链接和权重核验。血检指标受模块参与和检测子样本限制，不能按普通全样本解释。
- 认知：当前17个概念、341条候选字段映射。新增20个2018词语辨识字段；保留逐题响应，没有推定总分。
- 功能/情绪、慢病诊断、症状、社区与工作环境均保留波次差异及路由注释。候选不等于分析变量。

## 当前原型与重建

本地原型只展示变量元数据，不含个人数据或真实关联结果。E/P目录可按波次、概念、变量码、标签及模块搜索；认知、血检、癌症部位、残疾史、社区/工作等专题另有字段级映射页。

```powershell
python scripts/build_ep_atlas_metadata.py
python scripts/summarize_directory_scope.py
node --check site-prototype/dist/app.js
```

主要依据：`audit/ep_concept_mapping_coverage_v1.md`、`audit/cognition_item_audit_v1.md`、`audit/blood_biomarker_definition_review_v1.md`、`audit/indicator_scale_and_codebook_mapping_v1.md`及随项目保存的 CHARLS 官方波次问卷/代码本/指南。
