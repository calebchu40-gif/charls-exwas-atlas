# CHARLS wave-specific target and weight matrix (v1, review draft)

**Status:** source-grounded working matrix; not an independent statistical approval and not an analysis authorization. Updated 2026-10-29. Participant-level files and row-level QA remain in the protected local/server workspace.

## Default analysis structure

The project will start with wave-specific cross-sectional associations. Each wave has a separate sample flag, target population, module eligibility, nonresponse adjustment, and measurement protocol. The estimates will not be pooled or interpreted as within-person change by stacking wave records. A longitudinal question requires a separately specified risk set, follow-up/attrition and death treatment, analysis-specific weight, repeated-person covariance handling, and survey design review.

Weight values or positive/nonmissing weights do not establish sample eligibility. Use the official sample flag and module-specific inclusion rules, then apply age 45+ as a domain when that is the target. Construct the full valid design before subpopulation/domain estimation where supported.

## Cross-wave decision

现有 runner 与本矩阵的逐项映射、尚未实现的波次配置及执行顺序见 [`multwave_runner_configuration_compatibility_review_2026-10-29.md`](multwave_runner_configuration_compatibility_review_2026-10-29.md)。矩阵行是目标/权重的来源备忘，不构成已冻结模型配置。

The primary estimand should be one wave-specific cross-sectional exposure–phenotype association at a time, with an explicit target (for example, the sampled 45+ respondent population for that wave) and the weight for that target and module. Wave 1 and Wave 3 blood associations are not directly interchangeable because blood sampling/response, laboratory handling, fasting metadata, and blood weights differ. Wave 2 does not have venous blood measurements; Wave 4 and Wave 5 are not blood-lab waves. The 2018 and 2020 user guides state their PSU information is the same as in prior waves; they do not supply the missing county-stage/stratum/final sub-PSU crosswalk. A pooled blood ExWAS over these five waves is therefore not the default analysis.

Cross-wave summaries may be considered only after field-level concept/unit/route equivalence, target-population compatibility, common age domain, wave-specific weight applicability, variance support, and repeated-person dependence are reviewed. If these do not align, report wave-specific estimates and availability states. Never fill a wave with an absent measurement or reuse another wave's weight/code.

## Model authorization state

This matrix records source and design knowledge; it does not close the survey-design gate. Wave 1 lacks an identified respondent-to-final-sub-PSU key for split communities and a verified full variance-stratum/first-stage mapping. Until a defensible design variance method is documented and independently reviewed, no formal design-adjusted association model can be authorized. A community-level approximation, if considered, must be explicitly scoped and reviewed for its target and variance implications. The existing exploratory pilot output is not a formal or public result.
