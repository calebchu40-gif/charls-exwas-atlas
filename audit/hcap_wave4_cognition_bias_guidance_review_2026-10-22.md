# CHARLS-HCAP Wave 4官方偏倚提示与认知比较边界复核（2026-10-22）

## 官方文件与版本

CHARLS官方[2018 Wave 4发布页](https://charls.pku.edu.cn/en/Data/a2018_CHARLS_Wave_4.htm)仍列出`Data Alert`和`CHARLS-HCAP User Guidance`。本地保存并核验：`CHARLS_2018_Data_Alert.pdf` SHA1 `2D7628EC0151511D639E940BB35963B82969874E`；`CHARLS_2018_HCAP_User_Guidance.pdf` SHA1 `6A1E6C774360EB146587A4E407C2D9999C1D7E25`。两者分别为CHARLS团队2023-02-04数据提示、Alden Gross与Lindsay Kobayashi于2024-01-28发布的用户指南。PDF及文本提取保存在`sources_official/`。

## 数据质量与解释警示

- HCAP用于2018年60岁及以上受访者。不能把HCAP覆盖外推至45–59岁，也不能把结构性未施测解释成答错或零分。
- 2023 Data Alert指出MMSE若干题可能对识字、视力或普通话熟悉程度有偏倚：`dc019_w4`阅读并执行指令涉及识字和视力；`dc023_w4`造句涉及识字；`dc024_w4`重叠五边形临摹涉及识字与视力；`dc016_w4`手表命名和`dc017_w4`铅笔命名涉及视力。
- Data Alert还指出普通话改写的记忆词表及短语复述可能不利于非普通话使用者（`dc013_w4_1`、`dc015_w4`、`dc018_w4`），仙人掌命名（`dc026_w4`）可能受文化熟悉度和教育程度影响；CERAD十词中也有部分词语可能不熟悉。
- 2024 User Guidance要求检查“无法回答”“不知道”、拒答、未施测及其他非数值回答的比例与模式，并比较关键变量之间的差异性缺失。不同缺失原因可能反映认知、听视力、识字、语言理解或其他因素，不能合并为错误或一般缺失后忽略。
- 指南建议考虑识字、语言和感官受限条件下的敏感性分析，但同时提醒限制样本可能改变目标人群或引入偏差；本项目不自动排除这些受访者，必须先定义估计目标并审查缺失机制。
- Wave 4十词记忆测验的内容和施测方式不同于前几波；Wave 4使用三轮即时回忆（此前为一轮），这会抬高延迟回忆并使原始纵向变化看起来更陡。用户指南建议纵向记忆分析采用等百分位等值分数；本站保留逐题、逐波原码，不直接合并或生成跨波总分。

## 项目实现

`scripts/enrich_cognition_value_labels.py`现把一般HCAP适用范围、缺失解释、敏感性分析边界附到2018认知概念，并为数据提示列出的具体字段加入题目级警示。认知页面最后一列同时显示字段专属说明和概念级说明。该目录功能仅展示官方解释限制，不计算认知分数、不更改原始编码，也不代表已经核实个体层面缺失原因。

与Data Alert对照时还发现，2018 `dc026_w4`仙人掌命名及Codebook中的`dc026_w4_revised`虽在官方原始变量清单中，却未进入原认知条目crosswalk。现新增一个语义知识候选概念，把原题和修订版同列为同一任务的两个评分字段；不按独立认知指标计数。两字段分别保留Codebook类别（原题含99=Other，修订版未列该类别，不含频数）。修订版的具体改码规则仍需官方定义，因此不得自行重算或把两版同时计入分析。
