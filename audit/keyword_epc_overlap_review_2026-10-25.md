# Exact source-verified E/P overlaps among generic C keyword hits (2026-10-25)

## Scope

The C catalogue is a search aid for measurement, route, design, and possible adjustment context; a C label does not establish confounder status. We linked 47 rows only when an exact field was present in both the wave-specific official Codebook and Questionnaire evidence and the E/P crosswalk had one unambiguous exact wave+module match. Questionnaire evidence may be an exact flattened field code or a frozen parent-question/answer-slot anchor for looped fields; the updater requires the corresponding exact Codebook heading and does not use loose keyword matches. Five additional 2011 Codebook fields were verified after recognizing that the source PDF extraction changes `_` before a numeric suffix into a space (for example, `da070_2` becomes `da070 2`); the updater recognizes only an exact normalized Codebook bullet heading. The separate 2011 social-activity frequency field is audited under [`social_exposure_c_overlap_review_2026-10-25.md`](social_exposure_c_overlap_review_2026-10-25.md), where its parent-question route and source-version discrepancy are retained. The reproducible field-level list is [`keyword_epc_overlap_review_v1.csv`](keyword_epc_overlap_review_v1.csv); the updater is [`apply_keyword_epc_overlap_review.py`](../scripts/apply_keyword_epc_overlap_review.py).

The 47 rows cover smoking initiation/cessation (8), alcohol start/stop (8), education attainment (6), current hukou type (5), sleep duration (3), current hukou location (3), prostate illness (4), reported brain/intellectual disability (6), prior-wave education (1), prior-interview hukou-location relation (1), and recent-stroke age (2). Wave distribution: 2011 (11), 2013 (10), 2015 (9), 2018 (13), 2020 (4).

## Review boundary

Both official sources corroborate field identity, not respondent-level storage, eligible denominators, or analysis readiness. Existing E/P response labels, units, and mapping statuses remain intact; this update adds the link and source references without recoding responses. The C entry is explicitly metadata-only. A field must not be used as a covariate in its own focal association; any other adjustment role requires an estimand-specific causal rationale. This work does not create a default covariate set.

The earlier inventory had 50 generic keyword-only C/E/P overlaps. Five more links were confirmed through exact normalized 2011 Codebook headings; seven additional clinical C/P links were verified by matching exact Codebook fields to the Questionnaire's numbered disability option or parent follow-up item/route. The 2011 `DA057_8_` overlap is separately documented in the social-exposure review. Two current-wave `da005_2_` C records (2013 and 2015) remain unlinked: those Codebooks show the `zda005_2_` prior-wave field but no exact current-wave field, so the same-field identity is not established. All added rows retain route and analysis caveats. The updater hard-codes the reviewed key set and questionnaire anchors so that new candidate rows cannot be silently included.

No respondent-level values, Codebook frequencies, association models, or analytic sample sizes were used. The E/P/C catalogue remains 4,845/2,082/982 rows and the exact 92-entry analysis lock set is unchanged.
