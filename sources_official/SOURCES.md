# Official CHARLS source documents included with this project

These documents are public CHARLS questionnaires, codebooks, or data-release notes copied for reproducible variable-definition review. They contain no CHARLS respondent-level data. The source copies used for this handoff were obtained from the official CHARLS documentation archive at `https://charls.pku.edu.cn/` and are listed by survey wave below.

**2011 questionnaire source correction (2026-10-16):** `CHARLS_2011_Baseline_Questionnaire_official.pdf` and its extracted text are mislabeled: the PDF is “Followup Questionnaire 2013” (Jan 2015), and is excluded as 2011 evidence. The correct official baseline household questionnaire was obtained from the CHARLS 2011 baseline page as `CHARLS_2011_Baseline_Household_Questionnaire.doc` and extracted to the adjacent `.txt`. It identifies itself as the August 2011 baseline questionnaire (196 Word pages). Cite that DOC/extract for 2011 question wording and routing; cite the official codebook separately for variable codes and released value labels. The old mislabeled PDF is retained only for traceability.

- 2011: Baseline Household Questionnaire (official DOC and extracted text), National Baseline User Guide (PDF and extracted text; SHA-1 `72EDC4A96700D20E0361058A2EC543DF000ACEC6`), Blood Data Users' Guide (PDF and extracted text), Codebook extracted text.
- 2013: Questionnaire, Biomarker Questionnaire, Codebook (PDF and extracted text), Wave 2 Release Note (PDF and extracted text; SHA-1 `8F4A90C3DBADB49711333AB1E689BF2756583932`). The release note documents separate cross-sectional/longitudinal weights, a cross-sectional biomarker weight, and PSU dataset contents.
- 2015: Questionnaire, Biomarker Questionnaire, Codebook, Blood Data Release Note (PDF and extracted text).
- 2018: Questionnaire (PDF and extracted text), Codebook (PDF and extracted text; PDF SHA-1 checked against CHARLS release page), Wave 4 User Guide (PDF and extracted text; official SHA-1 `18D92656677464D10096377E1864DB59BD4DAA51`). The guide confirms Wave 4 weights, cross-sectional sample flags, the earlier-wave biomarker schedule, PSU continuity, and HCAP age scope.
- 2020: English and Chinese Questionnaires and Flowcharts (PDF and extracted text), Codebook (PDF and extracted text), Wave 5 User Guide (PDF and extracted text; SHA-1 `349B20961516D11F8E395D54209B502D9EA56A0F`). The Chinese questionnaire and flowchart are needed to interpret a known English activity-duration translation discrepancy and its skip routing.

Extracted text files are convenience copies for search; the corresponding PDF remains authoritative where included. The official 2011 Wave 1 page lists a Codebook but does not expose its file link in unauthenticated HTML. A second official route is the [Peking University Open Research Data Platform's 2011 baseline dataset, version 1.1](https://opendata.pku.edu.cn/dataset.xhtml?persistentId=doi%3A10.18170%2FDVN%2FIZU8OF&version=1.1), which lists `CHARLS_codebook.rar` (file ID 136; platform MD5 `293eb9789ee559fe0d7099086a2aaf40`; described as “数据编码参考书”). The file page indicates that sign-in/access is required; the archive has not been acquired or inspected for this project, so its contents cannot yet be cited for any specific field or value label. The project currently includes the previously extracted 2011 codebook text, but not the archive/PDF. The 2018 codebook PDF was obtained directly from CHARLS (`https://charls.pku.edu.cn/en/data/Codebook2018.pdf`) and its SHA-1 matches the official page entry. The 2018 download page is `https://charls.pku.edu.cn/en/Data/a2018_CHARLS_Wave_4.htm`; the 2011 page is `https://charls.pku.edu.cn/en/Data/a2011_CHARLS_Wave1__Baseline_.htm`. Always check current official releases before citing a codebook version in a publication.

The official 2015 wave page lists the Blood Data file and its release note. The official CHARLS announcement states the 2015 blood data were publicly released on 2019-06-20 and directs users to register/sign in to download. Official release note: https://charls.pku.edu.cn/en/data/Blood2015.pdf. Wave page: https://charls.pku.edu.cn/en/Data/a2015_CHARLS_Wave_3.htm. The release note reports 13,420/21,100 responses overall (63.60%) and 13,013/20,284 in the cross-sectional sample (64.15%); it releases a cross-sectional Blood_weight, while panel weights depend on the analysis.

The 2020 Chinese questionnaire and flowchart were obtained from the official CHARLS [Wave 5 Chinese documentation page](https://charls.charlsdata.com/pages/Data/2020-charls-wave5/zh-cn.html). Local SHA-1 values: `CHARLS_2020_Questionnaire_Chinese.pdf` `307FB0F902E76FD08E07222324A4CE5FA24FEC99`; `CHARLS_2020_Flowchart_Chinese.pdf` `83DA535E9542AD6974FF3474B7FE0FCDED0ED0BD`. Their extracted text files are search aids. The questionnaire (PDF p.36, printed p.30) confirms DA035's 30-minute categories; the flowchart (PDF p.30, printed p.24) establishes the conditional DA034-to-DA035/DA036 route. The English questionnaire's “30 hours” wording is a translation discrepancy; it is not used to override the matching Chinese questionnaire and Codebook.

The 2011 baseline household questionnaire DOC is linked from the [official 2011 baseline page](https://charls.pku.edu.cn/sj/a2011nqgjxdc.htm) (`https://charls.pku.edu.cn/sj/jiahuwenjuan2011.doc`). Local copy: `CHARLS_2011_Baseline_Household_Questionnaire.doc` (2,224,128 bytes; SHA-1 `18efb28804fdbc975e3d334c845a179493bb6221`). On 2026-10-27, a fresh download from that exact official URL was byte-identical to the archived copy (SHA-1 match); SHA-256 of the checked bytes is `689a7365fa93ae7996f2c352df53d4b4254edad29efe936f0f343d834828bbb1` (locally computed identity hash, not an official checksum). The adjacent `_extracted.txt` is a search aid. The CHARLS [2011 English baseline documentation page](https://charls.pku.edu.cn/en/Doc/a2011_CHARLS_Wave1__Baseline_.htm) also lists the baseline questionnaire. The project’s separate `CHARLS_2011_Baseline_Questionnaire_official.pdf` remains identified as a 2013 follow-up and must not be used for baseline citations.

Wave 4 sampling and weight interpretation is documented in `audit/charls_wave_sampling_and_weight_status_2026-10-22.md`. The Wave 4 User Guide was downloaded from the official [CHARLS Wave 4 guide](https://charls.charlsdata.com/Public/ashelf/public/uploads/document/2018-charls-wave4/application/CHARLS_2018_Users_Guide.pdf); its local SHA-1 matches the official release page. Weights and sample-info data files are listed on the official page but require CHARLS account sign-in; they are not included in this source bundle.

The current official [CHARLS data-use agreement](https://charls.charlsdata.com/users/sign_up/agreement/en.html) restricts data to academic study, prohibits publication of original microdata, and prohibits giving another person access. It also requires an acknowledgment thanking Peking University's National School of Development and China Social Science Survey Center; for publications using the 2011 national baseline it specifies the 2011–2012 National Baseline Users' Guide citation. The public atlas therefore keeps only field-level metadata and will expose only disclosure-reviewed, non-identifiable aggregate results. Each researcher must follow current registration and access requirements. The site's current footer carries the acknowledgment and links the official baseline guide; any future results paper must include the full citation and wave-specific acknowledgments required by the applicable release terms.
